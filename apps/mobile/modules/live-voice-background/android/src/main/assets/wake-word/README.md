# On-device wake-word model

This folder contains the int8 GigaSpeech Zipformer keyword spotting model from sherpa-onnx, configured for “Hey OpenBot”. The model and the sherpa-onnx runtime are Apache-2.0 licensed. The model recognizes English phonetics; Japanese-accent accuracy and false-trigger rates still need Pixel 7a evaluation.

Upstream model: https://github.com/k2-fsa/sherpa-onnx/releases/tag/kws-models
Upstream runtime: https://github.com/k2-fsa/sherpa-onnx
